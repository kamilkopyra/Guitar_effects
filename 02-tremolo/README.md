# Tremolo

<img src="tremolo-finished.jpeg" width="400">

The tremolo pedal was my second build, but the first one designed 100% by myself.

Tremolo is a way of modulating volume.
To achieve it I used two transistors, and with the help of a capacitor connected between them I created a simple LFO circuit that controls the brightness of an LED.
The LED sits in a black tube together with a photoresistor, so the photoresistor creates variable voltage drops that follow the LFO.

This project was also the first time I designed a pedal enclosure and 3D printed it.
