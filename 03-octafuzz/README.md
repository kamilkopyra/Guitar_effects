# Octafuzz

<img src="octafuzz-finished.jpg" width="400">

Octafuzz was my third build and the first time I used an already existing schematic.
It is based on Tim Escobedo's **Push Me Pull You** design, which uses an NPN and a PNP transistor with similar characteristics in order to rectify the signal.
This creates an output with double the original frequency, which we call an octave.

## Playing tips

The octave effect is most noticeable when the fuzz control is set high and when using the bridge pickup on your guitar.
Strong, single-note lines in the middle or higher fret positions bring out the octave harmonics most clearly.
Chords tend to sound messy, but single notes produce that classic, sharp upper-octave tone.
