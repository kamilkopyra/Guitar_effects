# PT2399 echo

This build was my fifth guitar pedal design, and for this project I wanted to take things a step further —
it was the first time I designed a PCB from scratch.

The circuit is based on the **PT2399** chip, a digital delay IC. My design improves on the reference circuit from the PT2399 datasheet:

- two controls: **delay time** and **repetitions**
- input and output buffers for better sound quality
- changes to the sound filtering
